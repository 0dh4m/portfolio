Architecture Logicielle & Transactions PDO

Conçu sous le paradigme Programmation Orientée Objet (PHP 8 OOP), chaque entité du domaine possède sa classe dédiée encapsulant les requêtes préparées PDO contre toute injection SQL :

  • Database.php : Singleton de connexion PDO avec gestion du charset UTF-8 et gestion des exceptions.
  • Chambre.php : Manipulation des chambres (CRUD, mise à jour des états Disponible / Occupée / Nettoyage).
  • Reservation.php : Gestion des réservations avec beginTransaction() et rollBack().
  • Client.php : Gestion du registre des clients, vérification des doublons CIN et historique de séjour.

Modélisation Relationnelle 3NF (`gestion_hotel.sql`)

-- Table des Chambres

CREATE TABLE chambres (id_chambre INT PRIMARY KEY AUTO_INCREMENT, numero VARCHAR(10) UNIQUE, type VARCHAR(50), prix_nuit DECIMAL(10,2), statut ENUM('Disponible','Occupée','En Nettoyage'));

-- Table des Réservations

CREATE TABLE reservations (id_reservation INT PRIMARY KEY AUTO_INCREMENT, id_client INT, id_chambre INT, date_debut DATE, date_fin DATE, statut_reservation ENUM('Confirmée','Terminée','Annulée'), FOREIGN KEY (id_client) REFERENCES clients(id_client), FOREIGN KEY (id_chambre) REFERENCES chambres(id_chambre));
